# documentAll — Privacy Policy

Public privacy policy and support page for the **documentAll** document viewer app (iPhone, iPad, Mac).

- Privacy policy: https://hexisteme.github.io/documentall-privacy/
- Support: https://hexisteme.github.io/documentall-privacy/support.html
- Bilingual: English / 한국어
- Documents stay on the device. iPhone and iPad show Google AdMob ads; the Mac app has no ads.
